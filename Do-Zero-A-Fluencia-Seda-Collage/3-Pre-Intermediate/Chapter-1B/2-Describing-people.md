# Describing People: Personality & Appearance

Vocabulário essencial para descrever **personalidade**, **intensidade** e **aparência física**, além da ordem correta dos adjetivos em inglês.

---

### 1. Personalidade (Adjetivos Opostos)

| Positivo / Neutro | Oposto | Tradução |
| :--- | :--- | :--- |
| **clever** | **stupid** | inteligente / estúpido |
| **friendly** | **unfriendly** | amigável / antipático |
| **funny** | **serious** | engraçado / sério |
| **generous** | **mean** | generoso / mesquinho |
| **kind** | **unkind** | gentil / indelicado |
| **hard-working** | **lazy** | trabalhador / preguiçoso |
| **extrovert** | **shy** | extrovertido / tímido |
| **talkative** | **quiet** | falante / quieto |
| **sociable** | **antisocial** | sociável / antissocial |

---

### 2. Intensifiers (Intensificadores)

Usamos intensificadores antes dos adjetivos para modular o grau da característica:

| Intensifier | Grau | Exemplo |
| :--- | :--- | :--- |
| **not very** | pouco / não muito | *He is **not very** talkative.* |
| **fairly** | razoavelmente | *She is **fairly** friendly.* |
| **quite** | bastante | *He is **quite** funny.* |
| **very** | muito | *She is **very** hard-working.* |
| **too** | demais (excesso) | *She can be **too** talkative sometimes.* |

---

### 3. Aparência Física (Appearance)

| Parte do Corpo / Característica | Vocabulário |
| :--- | :--- |
| **Nose** *(Nariz)* | *a big / a long / a small / a large nose* |
| **Mouth / Lips / Teeth** | *(a) big / (a) small mouth/lips* • *white teeth / yellow teeth* |
| **Ears** *(Orelhas)* | *big / long / small / large ears* |
| **Eyes** *(Olhos)* | *big / small / blue / green / brown / expressive eyes* |
| **Facial Hair** *(Barba/Bigode)* | *beard* (barba) • *mustache* (bigode) |
| **Hair Colour** *(Cor do cabelo)* | *red hair* • *dark hair* • *colored hair* |
| **Hair Style** *(Estilo do cabelo)* | *curly hair* • *straight hair* • *shaved hair* • *bald* (careca) |
| **Hair Length** *(Comprimento)* | *short hair* • *long hair* |
| **Skin** *(Pele)* | *dark skin / black skin* • *brown skin* • *white / fair skin* |

> [!NOTE]
> Para dizer que alguém é careca, usamos o adjetivo **bald** diretamente com o verbo *to be* (*He is bald* / *He's getting bald*), e não *"bald hair"*.

---

### 4. Ordem dos Adjetivos (Adjective Order)

Quando usamos dois ou mais adjetivos juntos para descrever cabelo ou olhos (sem usar *and*), eles seguem esta ordem fixa:

**Fórmula:** `Size (Tamanho)` $\rightarrow$ `Style (Estilo)` $\rightarrow$ `Colour (Cor)` + `Noun (Substantivo)`

* *She has **long curly** hair.* (`Size` + `Style`)
* *He has **big brown** eyes.* (`Size` + `Colour`)
