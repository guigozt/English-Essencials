# Form Questions: What Do You Do? (Fazendo Perguntas)

Exemplos práticos de diálogos para treinar perguntas e respostas sobre **origem**, **trabalho**, **estudos** e **vida pessoal** em inglês.

---

### 1. Diálogo 1: Isabella Huang (Origem e Moradia)

| | Diálogo |
| :--- | :--- |
| **Q:** | *What's your full name?* |
| **A:** | *My full name is Isabella Huang.* |
| **Q:** | *So... Huang is your family name, right?* |
| **A:** | *Yes, it is! It's a very common name in Taiwan. My father is Taiwanese.* |
| **Q:** | *Oh, I see... Where were you born?* |
| **A:** | *I was born in Taiwan... city of Taipei, to be more specific.* |
| **Q:** | *Nice! Where do you live now? Do you live in a flat or a house?* |
| **A:** | *I live in a flat in London.* |
| **Q:** | *Do you have any pets?* |
| **A:** | *Yes, I do! I have 2 female cats: Garlic and Mango.* |

> [!TIP]
> **Vocabulário útil:**
> * **Family name** = sobrenome (*last name / surname*).
> * **Flat** = apartamento (inglês britânico; equivalente a *apartment* no inglês americano).
> * **To be more specific** = para ser mais específico(a).

---

### 2. Diálogo 2: Alex (Trabalho e Idiomas)

| | Diálogo |
| :--- | :--- |
| **Q:** | *Hi, Alex! How's it going?* |
| **A:** | *I'm grand! Thanks for asking!* |
| **Q:** | *What do you do for a living? Do you like your job?* |
| **A:** | *I'm a software engineer. I love my job.* |
| **Q:** | *Oh! It sounds difficult. Where do you work?* |
| **A:** | *I work for Microsoft. It's a great company.* |
| **Q:** | *Cool! Can you speak any other language?* |
| **A:** | *I can, actually. My father speaks Japanese, so I learned a little bit from him. I can also speak Spanish quite well.* |
| **Q:** | *Do you think your job is stressful?* |
| **A:** | *It is, indeed... but I'm on holiday!* |

> [!TIP]
> **Expressões naturais:**
> * **How's it going?** = Como vão as coisas? / Tudo bem?
> * **I'm grand!** = Estou ótimo! (muito comum na Irlanda/Reino Unido).
> * **What do you do for a living?** = O que você faz da vida? (Qual é a sua profissão?)
> * **On holiday** = de férias (britânico; *on vacation* no americano).

---

### 3. Diálogo 3: Peter (Estudos e Universidade)

| | Diálogo |
| :--- | :--- |
| **Q:** | *Hi, Peter! What's the story?* |
| **A:** | *I'm great, thanks!* |
| **Q:** | *What do you study?* |
| **A:** | *I study biology. Marine biology, to be more specific.* |
| **Q:** | *What university do you go to?* |
| **A:** | *I go to Harvard University. It's really hard and strict.* |
| **Q:** | *What year are you in?* |
| **A:** | *I'm in the second year. I still have another 3 years to go until I graduate.* |

> [!NOTE]
> **What's the story?** é uma saudação informal (muito comum na Irlanda) que significa *"E aí, qual é a boa?"* ou *"Como estão as coisas?"*.
