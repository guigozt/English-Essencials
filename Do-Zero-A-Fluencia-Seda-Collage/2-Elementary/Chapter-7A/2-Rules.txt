✍️ Spelling Rules

1. Most regular verbs → + ed

| Base  | Past    |
| ----- | ------- |
| work  | worked  |
| play  | played  |
| watch | watched |
| ask   | asked   |
| dance | danced  |

2. Verbs ending in e → + d

| Base  | Past   |
| ----- | ------ |
| live  | lived  |
| close | closed |
| love  | loved  |
| move  | moved  |

3. Consonant + Y → y → ied

| Base  | Past    |
| ----- | ------- |
| study | studied |
| cry   | cried   |
| try   | tried   |


4. One vowel + one consonant → double the final consonant

When a short verb ends in one vowel + one consonant, we usually double the final consonant before adding -ed.

stop → stopped

plan → planned

shop → shopped

5. British English: travel → travelled

In British English:

travel → travelled

In American English:

travel → traveled
