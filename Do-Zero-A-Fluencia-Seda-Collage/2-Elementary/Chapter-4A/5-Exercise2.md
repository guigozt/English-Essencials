# Exercise 2: Word Order with Frequency Expressions

Ordene as palavras para formar frases gramaticalmente corretas no Present Simple, respeitando as regras de posição dos advérbios e das expressões temporais:

---

### Questões

a) our / hardly / teacher / angry / is / ever  
b) for / late / never / I / am / class  
c) you / work / every / day / to / do / drive ?  
d) don't / housework / do / we / our / always  
e) walk / I / every / work / to / day  

---

<details>
<summary><b>🔍 Ver Respostas e Análise Estrutural</b></summary>

<br>

a) **Our teacher is hardly ever angry.**  
* *Estrutura:* Sujeito (*Our teacher*) + verbo to be (*is*) + advérbio composto (*hardly ever*) + adjetivo (*angry*).

b) **I am never late for class.**  
* *Estrutura:* Sujeito (*I*) + verbo to be (*am*) + advérbio (*never*) + adjetivo e complemento (*late for class*).

c) **Do you drive to work every day?**  
* *Estrutura:* Auxiliar interrogativo (*Do*) + sujeito (*you*) + verbo (*drive*) + complemento de lugar (*to work*) + expressão temporal ao final (*every day*).

d) **We don't always do our housework.**  
* *Estrutura:* Sujeito (*We*) + auxiliar negativo (*don't*) + advérbio (*always*) + verbo principal (*do*) + objeto (*our housework*).

e) **I walk to work every day.**  
* *Estrutura:* Sujeito (*I*) + verbo (*walk*) + complemento de direção (*to work*) + expressão temporal ao final (*every day*).
