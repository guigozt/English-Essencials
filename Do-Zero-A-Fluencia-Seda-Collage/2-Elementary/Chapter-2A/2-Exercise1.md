# Exercise 1: Imperatives & Everyday Commands

Complete as frases abaixo escolhendo o verbo de comando mais adequado para o contexto (**Open**, **Let's**, **Give**, **Turn**, **Don't**):

---

### Questões

1. It's hot in here. \_\_\_\_\_\_\_\_ the window!  
2. \_\_\_\_\_\_\_\_ stop there! I need to buy some water.  
3. I've got to make a call! \_\_\_\_\_\_\_\_ me my phone.  
4. This room is so dark. \_\_\_\_\_\_\_\_ on the lights, please!  
5. \_\_\_\_\_\_\_\_ worry! I'm a good driver.  

---

<details>
<summary><b>🔍 Ver Respostas e Justificativas</b></summary>

<br>

1. It's hot in here. **Open** the window!  
   * *Justificativa:* Comando afirmativo direto com verbo base para ventilar o ambiente.

2. **Let's** stop there! I need to buy some water.  
   * *Justificativa:* Proposta/sugestão para o grupo (*Let's = Let us*).

3. I've got to make a call! **Give** me my phone.  
   * *Justificativa:* Pedido/ordem direta com verbo na forma base.

4. This room is so dark. **Turn** on the lights, please!  
   * *Justificativa:* Phrasal verb *turn on* (ligar/acender interruptores).

5. **Don't** worry! I'm a good driver.  
   * *Justificativa:* Imperativo negativo usa a partícula **Don't + verbo base** (*Don't worry*).

</details>
