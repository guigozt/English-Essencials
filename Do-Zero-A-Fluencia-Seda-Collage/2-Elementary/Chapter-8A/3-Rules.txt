There is/are - There was/were

    We use there is/are to say that somebody or something exists. There was/were is the past of there is/are.:

    -   There is a book on the shelf / There are a guy at the front door
    -   There are two apples in the basket / There were two apples on the table

    Quick Rules:

    -   There is often contracted to there's. There are is not usually contracted.
    -   When we talk about things in a list of things we use the is/was if the first word in the list is singular or there are/were if the fisrt word in the list is plural

a/an, some and any:

    -   We often use there is/was - there are/were with a/an, some and any.
    -   Use some and any with plural nouns. Some not an exact number

    -   e.g: There are some pictures on the wall / There weren't any pictures on the wall

    -   Use some in (+) sentences and any in (-) and (?)
    -   e.g: There was some tools in the garage / Was there any orangesin the basket?

Present Simple

            Singular                    |               Plural    
    ---------------------------------------------------------------------------------
    + There's a vase on the shelf       |   + There are some pictures on the wall
    - There isn't a swimming pool       |   - There aren't any plants in the room
    ? Is there a bathroom downstairs?   |   ? Are there any neighbours with children?
    ----------------------------------------------------------------------------------
    + Yes, there is                     |   + Yes, there are
    - No, there isn't                   |   - No, there aren't

Past Simple

            Singular                    |               Plural    
    ---------------------------------------------------------------------------------
    + There was a vase on the shelf     |   + There were some pictures on the wall
    - There wasn't a swimming pool      |   - There weren't any plants in the room
    ? Was there a bathroom downstairs?  |   ? Were there any neighbours with children?
    ----------------------------------------------------------------------------------
    + Yes, there was                    |   + Yes, there were
    - No, there wasn't                  |   - No, there weren't
