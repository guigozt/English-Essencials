# Spelling Rules: Third Person Singular (-s, -es, -ies)

Regras ortográficas essenciais para flexionar os verbos na 3ª pessoa do singular (*He, She, It*) no Present Simple.

---

### As 3 Regras Principais

#### 1. Regra Geral: Acrescentar `-s`
Para a maioria dos verbos em inglês, basta adicionar **`-s`**:

| Forma Base (I / You / We / They) | 3ª Pessoa (He / She / It) |
| :--- | :--- |
| *I live in Brazil.* | *He **lives** in Brazil.* |
| *I work here.* | *She **works** here.* |
| *I play soccer.* | *It **plays** with the ball.* |

---

#### 2. Terminações Especiais: Acrescentar `-es`
Para verbos terminados em **-ch, -sh, -ss, -x, -z** ou **-o**, adicionamos **`-es`**:

| Terminação | Forma Base | 3ª Pessoa (He / She / It) |
| :---: | :--- | :--- |
| **-ch** | *watch* | *She **watches** TV.* |
| **-sh** | *wash* | *He **washes** the dishes.* |
| **-ss** | *kiss* | *She **kisses** her dog.* |
| **-x** | *fix* | *He **fixes** the car.* |
| **-o** | *go* | *She **goes** to school.* |
| **-o** | *do* | *He **does** his homework.* |

---

#### 3. Verbos Terminados em Consoante + `y`: Trocar por `-ies`
Quando o verbo termina com **consoante + y**, removemos o **y** e acrescentamos **`-ies`**:

| Forma Base | 3ª Pessoa (He / She / It) |
| :--- | :--- |
| *study* | *He **studies** history.* |
| *carry* | *She **carries** a heavy bag.* |
| *try* | *He **tries** his best.* |

> [!WARNING]
> **Cuidado com a exceção (Vogal + y):**  
> Se antes do **y** houver uma **vogal** (*a, e, i, o, u*), **não** mudamos para `-ies`; apenas acrescentamos `-s`:  
> - *play* $\rightarrow$ *plays* (*He plays piano*)  
> - *enjoy* $\rightarrow$ *enjoys* (*She enjoys music*)  
> - *buy* $\rightarrow$ *buys* (*He buys books*)
