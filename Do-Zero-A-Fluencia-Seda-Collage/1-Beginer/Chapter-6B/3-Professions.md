# Professions and Occupations (Profissões)

Lista de profissões comuns em inglês acompanhadas do artigo indefinido adequado (**a** ou **an**).

---

### Tabela de Profissões

| Profissão em Inglês | Tradução em Português | Artigo (*a / an*) |
| :--- | :--- | :---: |
| **An architect** | Arquiteto(a) | an |
| **A doctor** | Médico(a) | a |
| **A journalist** | Jornalista | a |
| **A waiter** | Garçom *(masculino)* | a |
| **A waitress** | Garçonete *(feminino)* | a |
| **A shop assistant** | Atendente de loja / Vendedor(a) | a |
| **A receptionist** | Recepcionista | a |
| **A police officer** *(policeman / policewoman)* | Policial *(policial homem / mulher)* | a |
| **A nurse** | Enfermeiro(a) | a |
| **A taxi driver** | Motorista de táxi | a |

---

### Dica de Uso com Profissões

> [!IMPORTANT]
> Em inglês, **sempre** utilizamos o artigo indefinido **a** ou **an** antes do nome de uma profissão no singular:
> - *He is **a** doctor.* *(Ele é médico — não diga "He is doctor")*
> - *She is **an** architect.* *(Ela é arquiteta)*
