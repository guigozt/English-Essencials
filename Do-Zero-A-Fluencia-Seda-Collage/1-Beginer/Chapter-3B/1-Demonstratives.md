# Demonstratives (Pronomes Demonstrativos)

Usamos os pronomes demonstrativos para indicar pessoas ou objetos próximos ou distantes de quem fala.

---

### 1. No Singular

- **This:** *Este / Esta / Isto* $\rightarrow$ Usado para o que está **perto**
- **That:** *Aquele / Aquela / Aquilo* $\rightarrow$ Usado para o que está **longe**

#### Diálogo 1 (Singular)
- **William:** *Excuse me. What's that?* (Com licença. O que é aquilo?)
- **Salesman:** *It's a hat.*
- **William:** *And... is this a bag?* (E... isto é uma bolsa?)
- **Salesman:** *No, it isn't. It's a T-shirt.*

---

### 2. No Plural

- **These:** *Estes / Estas* $\rightarrow$ Usado para o que está **perto**
- **Those:** *Aqueles / Aquelas* $\rightarrow$ Usado para o que está **longe**

#### Diálogo 2 (Plural)
- **William:** *I'm sorry... What are these?* (Desculpe... O que são estes?)
- **Salesman:** *They're mugs.*
- **William:** *And... Are those postcards?* (E... aqueles são cartões-postais?)
- **Salesman:** *No, they aren't. They're maps.*
