# Exercise 1: Word Order with "There is / are" & Prepositions

Reorganize as palavras embaralhadas para formar frases corretas e coerentes em inglês:

---

### Questões

1. towel / there / is / in / bathroom / a / the (?)
2. remote control / the / bed / on / is / the (+)
3. there / pillow / under / 's / a / bed / the (+)
4. are / any / oranges / there / in / basket / the (?)
5. some / clothes / are / there / in / cupboard / the (+)

---

<details>
<summary><b>🔍 Ver Respostas e Justificativas</b></summary>

<br>

1. **Is there a towel in the bathroom?**  
   * *Estrutura:* Pergunta no singular $\rightarrow$ *Is there* + substantivo singular (*a towel*) + preposição (*in the bathroom*).

2. **The remote control is on the bed.**  
   * *Estrutura:* Sujeito (*The remote control*) + verbo *is* + preposição de superfície (*on the bed*).

3. **There's a pillow under the bed.**  
   * *Estrutura:* *There's* (= *There is*) + item singular (*a pillow*) + posição inferior (*under the bed*).

4. **Are there any oranges in the basket?**  
   * *Estrutura:* Pergunta no plural $\rightarrow$ *Are there* + quantificador interrogativo (*any*) + substantivo plural (*oranges*) + preposição (*in the basket*).

5. **There are some clothes in the cupboard.**  
   * *Estrutura:* Afirmativa plural $\rightarrow$ *There are* + quantificador afirmativo (*some*) + plural (*clothes*) + preposição (*in the cupboard*).

</details>
