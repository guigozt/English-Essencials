# Numbers (0 to 10)

Números básicos em inglês de 0 a 10.

---

### Tabela de Números

| Número | Por Extenso | Pronúncia / Observação |
| :---: | :--- | :--- |
| **0** | **zero** / **oh** | *"oh"* (som da letra O) é muito comum em números de telefone |
| **1** | **one** | *uan* |
| **2** | **two** | *tu* |
| **3** | **three** | *thri* (som de *th* com língua entre os dentes) |
| **4** | **four** | *fór* |
| **5** | **five** | *faiv* |
| **6** | **six** | *siks* |
| **7** | **seven** | *séven* |
| **8** | **eight** | *eit* |
| **9** | **nine** | *nain* |
| **10** | **ten** | *ten* |
