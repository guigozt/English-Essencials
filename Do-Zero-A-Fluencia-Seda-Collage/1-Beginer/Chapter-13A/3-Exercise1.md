# Exercise 1: Offers and Invitations with "Would"

Organize as palavras para formar ofertas, convites ou pedidos corretos em inglês:

---

### Questões

1. orange / like / juice / you / would / an (?)
2. 'd / love / I / Yeah / to (!)
3. I / sandwich / please / a / like / 'd (.)
4. film / to / a / would / you / watch / like (?)
5. dance / would / like / you / to (?)

---

<details>
<summary><b>🔍 Ver Respostas e Justificativas</b></summary>

<br>

1. **Would you like an orange juice?**  
   * *Estrutura:* Oferta de bebida $\rightarrow$ *Would you like* + artigo (*an*) + substantivo (*orange juice*).

2. **Yeah, I'd love to!**  
   * *Estrutura:* Aceite entusiasmado a um convite $\rightarrow$ *I'd love to*.

3. **I'd like a sandwich, please.**  
   * *Estrutura:* Pedido educado $\rightarrow$ *I'd like* + item (*a sandwich*) + cortesia (*please*).

4. **Would you like to watch a film?**  
   * *Estrutura:* Convite para atividade $\rightarrow$ *Would you like to* + verbo no infinitivo (*watch*) + complemento (*a film*).

5. **Would you like to dance?**  
   * *Estrutura:* Convite direto para dançar $\rightarrow$ *Would you like to* + verbo na forma base (*dance*).
